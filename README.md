# Тебе, с любовью

Сайт на HTML, CSS и JavaScript. Откройте index.html в браузере или запустите локальный сервер.

## Фотографии

В каждой из шести глав по три фотографии. Поместите JPG в assets/photos с именами:

- Экран 1: 1-1.jpg, 1-2.jpg, 1-3.jpg — портреты девушки.
- Экран 2: 2-1.jpg, 2-2.jpg, 2-3.jpg — нежные совместные фото.
- Экран 3: 3-1.jpg, 3-2.jpg, 3-3.jpg — любимые общие воспоминания.
- Экран 4: 4-1.jpg, 4-2.jpg, 4-3.jpg — прошлый день рождения.
- Экран 5: 5-1.jpg, 5-2.jpg, 5-3.jpg — дорогие вам снимки.
- Экран 6: 6-1.jpg, 6-2.jpg, 6-3.jpg — три любимые фотографии для финала.

Пока файлов нет, видны декоративные карточки. Тексты и подписи редактируются в массиве pages в script.js. Тексты пока предварительные, персонализируем после получения вашей истории.

## Аудио

Поместите запись в assets/voice.mp3 и раскомментируйте две строки рядом с концом script.js. В окне «мой голос» можно временно выбрать запись для проверки: такой выбор не добавляет файл в сайт и не передаёт его другим посетителям. Автовоспроизведения нет, запись запускается кнопкой плеера.

## Публикация и обновления

Сайт готов для GitHub Pages: в Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). После каждого обновления файлов в main GitHub Pages автоматически обновит ту же ссылку. Публикуйте только файлы сайта, фотографии и аудио, которые хотите сделать доступными посетителям.

## Адаптация

При ширине от 1000 px письмо расположено по центру, одно фото слева и два справа. На телефоне сохранён альбом из трёх фото под текстом.

Мобильный макет, включая ширину 393 px у iPhone 14 Pro, safe-area, десктоп, настройки уменьшения движения и управление с клавиатуры. Шрифты загружаются из Google Fonts, без интернета используются системные.
